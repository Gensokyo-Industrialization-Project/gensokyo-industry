# Resource Production

The idea is making a new resource for upcoming Gensokyo world, this ore/resources is
- Spirit Quartz: 
    Base resource for fuel and other advanced manufacturing recipe
- Higanbana Lilies: 
    for late game recipe, some sort like tungsten ore in vulcanus
    probably for chemical thing and dye
    (not sure about this part probably going to get yelled by eiki)
- Tamahagane Sand: 
    Somesort inspired by the seablock angel & bob mod (that seablock modpack) where you make basic 
    resource (iron & copper) from water, it would be funny if you can
    melt down the result into molten iron

Available Base Game Ore:
- Uranium (low quantity)
- Coal (low quantity)
- Stone (low quantity)

---

## Production Overview

The production will be inspired by angel & bob mod where you crush the ore,
refine the ore,  smelt the ore, and then finally make the product, but for early game
you can use the ore as is like the base game ore but very inefficient.
